= Grails Micronaut Integration

Grails supports Micronaut through the `grails-micronaut` plugin. It uses the https://micronaut-projects.github.io/micronaut-spring/latest/guide/#springBootStarter[Micronaut Spring Boot Starter] so the Micronaut and Grails application contexts can run side by side.

Grails 8 Micronaut applications require JDK 25 or later.

== Dependencies

Apply one Grails Micronaut BOM as an `enforcedPlatform`, then add `grails-micronaut`:

[source,groovy]
----
dependencies {
    implementation enforcedPlatform("org.apache.grails:grails-micronaut-bom:$grailsVersion")
    implementation 'org.apache.grails:grails-micronaut'
}
----

Use `org.apache.grails:grails-hibernate5-micronaut-bom` or `org.apache.grails:grails-hibernate7-micronaut-bom` when the application targets the corresponding Hibernate generation.

The Micronaut BOMs import published Grails BOMs from Maven. They do not depend on a grails-core source checkout.
